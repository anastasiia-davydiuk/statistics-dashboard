    Створює файл із уже вбитими даними — його заливаєш на сайт або кидаєш у чат

    Хто що бачить. Той, хто відкриє файл звичайним посиланням, побачить лише два таби — Тракмаркет і Фінкар. Вкладок «Внести дані» та «Тижні» для нього просто не існує.

    Як зайти тобі. Додай #admin в кінець адреси (наприклад …/index.html#admin) і введи код. У межах вкладки браузера код питається один раз.

    Щоденний порядок дій: внесла тиждень → «Завантажити файл для публікації» → заміни цим файлом той, що лежить на сайті. Поки не заміниш — інші бачитимуть попередні цифри.

    Резервна копія — файл з усіма тижнями, через нього переносиш дані на інший комп'ютер.
